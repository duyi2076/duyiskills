# 固定构图合同

## 基准

- 正式逐词转写只接受豆包 Agent Plan ASR：`provider=agent_plan`、`resource_id=volc.seedasr.sauc.duration`，并绑定当前源视频 SHA-256 与字节数。禁止本机 ASR 和自动降级。
- 词级纠错采用“高置信才改、低置信保留并记录”：完成复核后不得因为单个无法唯一确定的词阻断整条视频。
- 参考画布：`1280×720`、16:9。
- 实际动画模板：`2560×1440`，即参考坐标的 2 倍；合成时只允许等比缩放。
- 源视频、截图和运行证据由调用方保存在 Skill 目录之外；分发包只包含测量后的合同。

小卡和中卡分别约占画面宽度 `29.14% / 33.36%`。中卡是默认值，也是任何普通卡片的宽度上限；横向范围不得因人物位置改变。

## 两档尺寸与关系布局

尺寸与布局是 AI 对真实口述作出的显式决定，不随机，也不按人物位置自动缩放。每个视觉 state 都要保存 `fidelity_mode/relation_layout/layout_reason/card_size/content_structure/size_reason`，并通过机械门禁。详细规则见 [卡片视觉语法](card-visual-grammar.md)。

- `small`：短标题、单一提示、路径卡头或一句短结论。
- `medium`：完整核心观点、普通对比、纵向列表、公式和所有关系布局；没有充分理由时固定选中卡。
- 2–4 个叙事推进节点单行排列，节点自然宽，剩余空间平均分给箭头通道；每条箭头绑定它所引出的后一个节点，在目标节点触发时同步生长，不得提前固定显示。
- 普通并列 3 项各占 `1/3`，4 项各占 `1/4`。
- 5–8 项按 `3+2 / 3+3 / 4+3 / 4+4` 换行；9–12 个同组短项可使用一个复合卡外壳，按 `4+4+1 / 4+4+2 / 4+4+3 / 4+4+4` 换行；13 项以上按真实语义边界拆章。
- 内容超出当前尺寸文字预算时，先提炼动画概念、拆层或逐项出现；禁止突破 `33.4%` 上限。
- 卡片不得为追求形式逻辑而改写说话者的节点、顺序、人物或关系。
- 卡片高度按实际内容自然生成，短标题不得继承大面积固定空底板；最终以浏览器加载真实字体后的 DOM 测量为准。

## 固定字体与双皮肤

动画结构、组件、坐标、字体、状态机和时长在两套皮肤中完全相同；皮肤只能改变受限的颜色、不透明度、边框、阴影、自由文字与板内文字角色。一条视频只能使用一套皮肤，不能按章节或内容随机切换。

- 默认深色 `dark-reference-fixed`：
  - 普通卡片必须使用 `#0A141B / 0.82`；实际输出不匹配该颜色与透明度则失败。
  - 主文字 `#F3F5F7`；次文字 `#A7ADB4`。
- 白墙融合 `white-wall-fusion-fixed`：
  - 仅在用户明确指定时使用，`auto_eligible=false`。
  - 舞台背景透明：`stage_feather_opacity=0`、`fullscreen_opacity=0`。
  - 自由文字直接落在画面上，主文字 `#17212B`、次文字 `#4F5963`，配轻浅色轮廓以保证跨过深色人物时仍清晰；轮廓不形成底板。
  - 类型组件使用局部深色半透明内容板 `#0A141B / 0.82`；板内主文字 `#F3F5F7`、次文字 `#A7ADB4`。
  - 不允许通过章节配置覆盖任何 paint token；需要改色必须修改全局皮肤合同并重新测试。
- 章节强调色只允许：
  - 蓝 `#2D78F4`
  - 红 `#FF315D`
  - 绿 `#20E5A0`
  - 黄 `#D8BE55`
- 英文章节标题：Space Mono Bold，全大写，高字距，使用章节强调色。
- 中文主信息：Noto Sans CJK SC Bold（700）。Black（900）仅允许用于语音字幕，不得用于动画卡片。
- 路径列表正文：Noto Sans CJK SC Medium（500），避免所有层级都像 Black 一样发沉。
- 中文副标题和辅助信息：Noto Sans CJK SC Regular。
- 所有上述字体文件必须来自 Skill 内资产，不允许系统回退。

两套皮肤都必须输出相同的 `timeline_contract`；相同 config 构建后的 DOM、GSAP 时间线、motion JSON 和 appearsBy 断言必须机械一致。

## 类型化组件

- `thesis`：深色主卡，可带标签 chips；标题允许一个强调色片段。
- `quote`：无外框引用区，引用符、可选强调色正文、圆形来源头像、来源名和注释形成一组。
- `comparison`：高 `81 px` 的强调色细边框行；必须使用语义 emoji、英文 kicker、中文标题和警告标记，不渲染第三行 body。
- `formula`：固定使用中卡，参考宽 `427 px`、高约 `60 px`；内容拆成白色主项、灰色关系符、强调色结论等分段，不把整句染成一种颜色。
- `relation`：使用中卡承载叙事推进、明确因果、并列、对照、层级与 5–12 项均衡网格；节点与顺序必须来自真实口述。
- 同一编号序列或同一并列组包含 9–12 个短节点时，`relation/multi-item` 使用一个复合卡外壳承载三行，item 仍逐项出现。
- `progressive-list/path`：通常使用小卡或中卡；参考路径标题卡宽 `373 px`、高 `75 px`，只含 kicker 和标题；下方编号与文字逐项追加，标题卡禁止第三行 body。
- `chat`：使用独立消息气泡，不套万能大卡。

禁止把以上类型重新渲染成同一种黑框。

## 动效

- 栏目进入：竖线、英文标题、中文副标题依次出现；首层内容至少晚 `0.30s`。
- 普通容器进入：固定坐标透明度渐显 `0.22s`，不平移、不缩放、不回弹。
- 逐项出现：固定坐标透明度渐显 `0.15s`。
- 普通退出：整组淡出 `0.22s`。
- `update` 的默认含义是追加下一层，禁止让上一层退出。
- 新层出现后，前层默认保持；只有语义明确否定时允许 `dim` 或 `cross-out`。
- 出现后完全静止。
- 全屏章节转场：只用于真正的身份/结论升级；约每 2–3 分钟最多一次。

## 连续语流剪切

- 优先使用 Silero VAD 的真实语音入口和能量低谷，不统一预留固定毫秒数。
- `呃然后` 等填充词与下一有效字首尾相接或轻微重叠时，使用采样级零交叉微切：交界前最多保留 `4ms`，交界后最多进入 `2ms`，并给新片段最多 `4ms` 淡入。
- 该策略只用于已经识别并决定删除的硬填充词；不得拿它缩短普通词、句尾或未说完的尾音。
- 机械门禁必须记录 `entry_strategy=continuous-speech-zero-cross-splice`；最终无上下文 AI 镜头仍要确认听不到填充词尾巴且下一字起音完整。

## 信息分工

- 人物：情绪、可信度、语气。
- 底部字幕：逐句原话。
- 左上舞台：概念、关系、对照和路径。

动画文字不得把字幕整句重复一遍。

## 语义揭示

- 栏目可以在主题句前最多 `0.30s` 建立，但实质信息必须等到对应原话开始后再出现。
- 每个 state、item 和 formula part 都绑定精确逐词证据；不能只证明它与整章主题有关。
- 列表项在说到对应概念时逐项出现；对比的第二面在转折词后出现；公式各部分按口述次序独立出现。
- 总结和结论不能在论证完成前提前展示。
- 持久层必须在本章剩余口述中持续相关；不再相关时应结束章节，而不是让旧卡跨主题悬挂。
- 机械审计只证明时间和证据一致，最终还要通过无上下文 AI 镜头连续观看判断语义是否自然。
