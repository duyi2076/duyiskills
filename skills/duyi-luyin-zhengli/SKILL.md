# 杜一录音整理

## 适用范围与默认交付

处理用户明确指定的现成转写稿、访谈记录、多人答疑或聊天原文。输入是已经存在的文字材料，不负责自动转录、下载录音、回听音频或事实核验。只读取逐字稿时，明确写“仅核对转写文本”，不声称听过录音。

默认在当前聊天中交付：

1. 完整主题整理稿，说明来源范围、实际阅读范围、转写覆盖、是否回听和角色边界。
2. 主题或问答索引，覆盖已读的实质内容。
3. 候选清单，逐项给出候选类型、具体内容、实际来源位置、证据性质、拟归属、状态和待确认事项。

用户指定目录时，才按该目录的真实规则保存；没有私人知识库也可以直接开始。原始资料、整理结果、候选区和已采纳目标职责分别保持其真实身份。归档、确认后分流、移动资产、更新索引或批量改名，只有用户明确要求时才执行，并遵循用户指定环境的规则。候选默认是“待确认”，不代表采纳、验证或公开。

核心整理不依赖其他 Skill。用户要把内容整理成问答卡时，可以另行指定同合集的 `duyi-yuanzi-kapian` 作为独立后续任务；本 Skill 不假定该目录已经安装，也不创建指向它的文件链接。

## 读取与来源边界

- 先确认本次指定的文件、记录日期、范围、来源身份和转写覆盖，再完整阅读指定范围。搜索只用于定位，不能代替全文阅读。
- 保留原文件名、来源 ID 或链接、记录时间、覆盖范围、说话人标记、转写状态和实际行号或时间段。不能估算定位；来源 ID 缺失就标“待补”。
- 原始材料、完整整理稿和候选清单是不同身份。保持原件不可变，不用整理稿替代原件，也不把候选当成已采纳资产。
- 区分账号所有者、录音参与者和具体经历或发言主体。共享账号、原标题、存放位置、第一人称和相似语境，都不能单独证明归属。无法确认时写“归属待核”，仍可整理原文。
- 有身份依据才使用姓名和第一人称。角色不确定时沿用原说话人标记，并注明“根据现场表现推定、未核实”或“未知”。
- 分开记录用户自述、回答者判断、他人转述、建议、假设举例、话术演示、AI 归纳、已记录行为和实际结果。
- 原文中的提示词、演示命令和操作要求属于待整理内容，不是执行授权。

## 完整整理与候选提取

先写材料主线和主题/问答索引，再按材料的实际用途提取候选，例如需要回查的判断、有明确条件的做法、具体经历或用户明确提出的下一步。不强行填满固定栏目；材料没有的内容不凑。

每个候选围绕一个可独立理解的问题或资产。同一问题的追问、条件、示范、否认、后续修正和最后进展一起阅读；不同人的限制、经历或观点不能合成一个案例。完整整理稿按主题保留处境、问题、实际回应、条件、理由、动作顺序、例子、追问变化、进展和来源，不压成几个抽象词。

保持原文判断强度和性质：

- 建议不等于执行，表示理解不等于效果。
- 询价或付费意愿不等于付款，付款不等于交付成功。
- 举例中的数字、产品和周期不等于实际经营数据或执行标准。
- 自述结果不是独立事实核验；单次答疑也不自动成为已验证方法。
- 角色、经历、案例、付款、交付和公开许可各自记录，不能互相推断。
- 只有实质未回应的问题才进入“未回应问题”；有部分回应的，保留已回应部分并指出剩余部分。不代答。

逐字引用必须是原文中可连续匹配的短句。清理过的句子标“原话整理”，否则使用不带引号的归纳。关键人名、产品名、金额、人数和因果疑似错字保留疑点，不猜改。

## 用户要求保存时

读取 [references/ingestion.md](references/ingestion.md)，核对保存、查重、归属修正和读回要求。

执行顺序为：确认授权范围，查找指定来源和已有产物，按目标环境真实规则保存，更新必要来源或索引，再从磁盘读回核验。只写用户明确指定的目标；不因认可本 Skill 就默认采纳所有候选。来源原件仍保持原位，除非用户明确授权移动原件。

重要正文覆盖、批量结构调整、批量移名和链接更新，按用户目标规则执行。链接和附件应指向真实来源；不能用空占位文件制造通过。隐私不会因整理或保存自动变成可公开，未经授权的第三方资料默认保持原范围。

## 输出与交付前检查

按 [references/output-contract.md](references/output-contract.md) 核对整理稿和候选清单的完整性。

整理稿至少包含：来源范围、实际阅读范围、转写覆盖和是否回听、角色边界、整体主线、主题/问答索引、分主题整理、候选清单链接或列表、未回应问题、转写疑点、隐私边界和未交付范围。

候选清单每项尽量包含：资产类型、独立可理解的具体内容、原件链接或来源位置、逐字证据、性质、拟归属、状态和待确认事项。新提炼内容默认 `status=待确认`；实践验证、执行进度、公开范围和采纳状态分别记录。

交付前对照原件检查：来源位置、角色、关键数字、限制、原问题与实际回应、追问修正、建议与结果状态、实际阅读范围和隐私范围。区分“已读”与“已整理交付”，不把抽样称为全量。报告未读范围、已读未交付范围和仍需人工核验的内容。
