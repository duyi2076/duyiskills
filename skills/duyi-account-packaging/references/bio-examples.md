## 简介写法参考

根据当前用户的真实材料，选择一到两种合适的写法。缺少对应材料时不硬填，昵称与简介可以共同承担辨识度和记忆点。

| 写法 | 信息顺序 | 适合的材料 |
|---|---|---|
| 串联经历 | 相关经历变化 → 当前视角或能力 → 持续分享什么 | 有经历积累、转变和明确内容方向 |
| 说明两个内容主题 | 一句总起 → 主题一及通俗解释 → 主题二及通俗解释 | 有两个能长期持续、彼此有关联的主题 |
| 表达个人主张 | 本人的态度或内容边界 → 读者获得的价值 → 真实实践线索或内容入口（可选） | 有明确个人表达和能够兑现的内容价值 |
| 讲述经历转折 | 过去积累 → 当前转折或行动 → 持续记录的内容与具体范围 | 有正在发生的变化、实践过程和分享方向 |
| 呈现价值取舍 | 当前真实状态 → 本人坚持的原则或取舍 → 内容与表达承诺 | 有本人已明确的价值判断和自然说法 |

## 使用方法

- 先读本人原话、当前包装和写法参考，根据材料选择组织方式。参考只借写法，不借他人的身份、经历、成绩或特有表达。
- 材料足够时直接起稿；有缺口再从授权库查找或定向补问。已有姓名、当前状态或采纳句时直接沿用，不重复访谈。
- 给其他用户做账号包装时，使用其本人的材料。示例中的“无限游戏”、行业方向和个人经历不是通用答案。
- 对每版实际文案执行五项审核和字符检查；审核结论以当前文案为准。
