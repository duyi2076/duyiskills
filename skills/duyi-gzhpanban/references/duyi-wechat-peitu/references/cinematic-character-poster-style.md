# Cinematic Character Poster Style

这套风格用于杜一公众号的强叙事封面、首图和正文阅读分镜。目标是原创的动画电影式角色叙事，不是截图复刻、电影仿品、奖项海报或社交平台内容搬运。

以本文的视觉规格为准；使用者提供参考图时，仅用于构图、角色质感和光影校准。

## 适用场景

- 个人选择、职业转型、AI 时代普通人路径、学员故事、失败复盘、成功故事。
- 文章有明确主角、压力、选择、转变或孤独行动时。
- 需要比商业编辑插画更强情绪、更强点击感的封面、首图或正文分镜。
- 正文中存在连续的阅读节点：处境、压力、旧路、转身、行动、抵达。

不适用：

- 工具教程、参数说明、严肃数据分析、流程拆解。
- 需要可信、克制、B2B 专业感的文章。
- 只是在正文里补空白、凑版式、做装饰时不用。

## 视觉 DNA

- 一个原创 3D 动画角色是绝对主角：比例略夸张，脸部有雕塑感，表情克制但有故事；除非需要匿名感，优先露出正脸、四分之三侧脸或强侧影。
- 构图像电影主视觉：中心人物、低机位或平视、背景有世界观线索，底部或侧边预留标题空间。
- 光影有电影感：逆光、边缘光、雾气、暗部层次、冷暖对比。
- 质感是动画电影关键帧，不是写实剧照、真人电影海报或普通概念场景图。
- 情绪是命运感、选择感、压力感、孤独行动感，不走可爱、网感、科技炫光。
- 画面可以有英文质感，但最终中文标题优先后期排版；不要依赖模型生成复杂中文。
- 色彩按主题选择：深蓝/灰绿/暖橙/旧金/雾白，控制在 2-3 个主色，不做花哨渐变。

## 内容转译流程

### 1. 先判断能不能用

四问全过，才使用 cinematic-character-poster：

```text
有没有主角？       读者化人物 / 匿名案例主角 / 作者视角 / 群体代表
有没有压力？       外部压力或内心冲突，不只是抽象趋势
有没有选择动作？   能被画成一个具体动作或空间关系
文章是否承接？     文章里真的会交付这个故事或选择，不是封面空喊
```

缺任意一项，默认不用这个风格，改走 editorial-illustration 或小黑。

### 2. 把文章压成一句话

```text
这篇文章帮 {读者} 在 {具体场景} 看见/解决 {真实问题}，核心改变是 {改变}。
```

### 3. 提炼角色系统

```text
主角：一个正在转型的普通内容创作者
压力：AI 工具很多，但没有自己的分发入口
场景：深夜城市路口，身后是闪烁的信息屏，前方有一扇小门亮着
情绪：不是追风口，而是找到入口
```

如果一篇文章要用多张 cinematic 正文图，先固定连续性：

```text
主角固定：同一年龄感、发型、衣服、核心物件
核心物件：笔记本 / 简历 / 旧电脑 / 纸箱 / 门票 / 一盏灯
主色关系：冷色压力 + 暖色选择，或灰绿现实 + 旧金微光
视觉母题：门 / 路口 / 桥 / 窗 / 灯 / 影子 / 雨 / 人群
```

### 4. 选正文分镜节点

只选真正帮助阅读的节点，不平均配图。

| 节点 | 阅读功能 | 画面任务 |
|---|---|---|
| 开场处境 | 让读者进入“这说的是我” | 主角站在问题现场 |
| 压力逼近 | 放大外部压力或内心冲突 | 压力物围上来，但不画结果 |
| 旧路失效 | 说明过去方法不再有效 | 主角背着旧工具走不动 |
| 关键选择 | 文章的转折点 | 主角面对门、桥、岔路、按钮 |
| 行动代价 | 让方法变成行动 | 主角搬、拆、写、交付、等待 |
| 抵达/回望 | 给段落收束，不夸大成功 | 看到一点光，不画奖杯和结果承诺 |

### 5. 生成画面任务

```text
画面任务：{首图情绪入口 / 分享封面 / 正文阅读分镜}
分镜节点：{开场处境 / 压力逼近 / 旧路失效 / 关键选择 / 行动代价 / 抵达回望}
主角正在：{一个动作}
身处：{具体场景}
被：{压力物} 包围/推动
面前出现：{选择物}
手中物件：{能代表文章核心证据或行动的物件}
情绪：{清醒 / 犹豫 / 孤独行动 / 转型前夜}
禁止画：{真实品牌、真实肖像、offer、证书、收入数字、奖项、平台 UI、未证实结果}
插入位置：{标题下首图 / 某个段落前 / 某个段落后}
一句验收：读者看图后应该觉得：这不是漂亮人物图，而是我/这个案例正在面对的那个选择。
```

### 6. 决定图型

| 图型 | 画面重点 | 字 |
|---|---|---|
| 21:9 首图 | 角色 + 场景冲突 + 标题安全区 | 可后期加短标题 |
| 1:1 分享封面 | 强角色半身 + 强标题区 | 短标题 |
| 4:5 海报测试图 | 仅用于风格探索，不作为公号首图主比例 | 尽量无字或只留标题区 |
| 正文 16:9 | 阅读分镜，承接段落节奏 | 无字 |
| 正文 3:4 | 人物故事特写或情绪节点 | 无字 |

## 正文配图数量

| 文章类型 | cinematic 用法 |
|---|---|
| 观点文 / 方法文 | 0-1 张，通常只做首图或关键转折 |
| 案例复盘 / 转型故事 | 2-4 张，按分镜节点插入正文 |
| 长篇人物故事 / 视觉专题 | 4-6 张，但每张必须对应一个段落功能 |

如果一张图删掉后不影响阅读理解或情绪递进，说明它只是装饰，不要放。

## Prompt 骨架

```text
Generate an original cinematic animated character poster for a Chinese WeChat article.

Core idea:
{一句话主题}

Character:
{原创主角身份、年龄感、姿态、服装、手中物件}

Story beat:
{分镜节点 + 对应段落功能}

Conflict scene:
{场景、压力来源、前景/背景关系}

Composition:
{21:9 / 1:1 / 16:9 / 3:4} WeChat cover or inline composition, one central stylized 3D animated human character, clear silhouette, cinematic rim light, volumetric haze, warm/cool contrast, clean focal area. Use 21:9 for article hero images, 16:9 for most inline story frames, 3:4 for character close-ups, and 4:5 only for exploratory poster tests.

Mood:
{选择感 / 转型感 / 孤独行动 / 压力下的清醒}

Text:
No baked-in large readable title unless exact text is explicitly requested. Leave clean space for later Chinese title typesetting.

Negative constraints:
No fake awards, no laurels, no critic quotes, no ratings, no credits block, no watermark, no username, no social media UI, no phone screenshot, no logos, no real movie imitation, no named studio style, no celebrity likeness, no direct copy of any reference image.
```

## 和现有风格的分工

| 风格 | 负责什么 | 失败信号 |
|---|---|---|
| editorial-illustration | 专业、克制、商业隐喻、长期品牌感 | 太像 PPT 或信息图 |
| cinematic-character-poster | 封面/首图的情绪入口，正文阅读分镜 | 太像电影仿品、奖项海报或装饰画册 |
| xiaohei | 荒诞机制、系统里的脏活、白纸草图 | 太可爱或太像课程图 |

## 失败信号

- 出现平台 UI、账号水印、点赞按钮、短视频截图痕迹。
- 出现虚构奖项、月桂、影评 quote、星级评分或片尾 credits block。
- 画面像在仿某部具体动画电影或某个真实工作室。
- 画面太写实，只像真人电影剧照或城市概念图。
- 主角只有背影，缺少可记忆的脸部和人物性格。
- 角色太可爱、太网感、太游戏皮肤、太赛博。
- 只有漂亮角色，没有文章冲突。
- 画了文章没有证据支持的结果，例如 offer、证书、收入数字、名校、奖杯、平台数据。
- 封面冲突和标题/开头不一致，读者点进来后文章没有承接。
- 正文连续使用 cinematic 图，但没有段落功能，只像故事片宣传页。
- 多张图里的主角、物件、色彩和视觉母题不连续，像不同项目拼贴。
- 中文标题由模型直接生成且错字明显。
- 画面元素太满，移动端缩小后只剩一团暗色。
