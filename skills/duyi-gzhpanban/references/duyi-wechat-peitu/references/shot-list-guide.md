# 配图策略指南（Shot List）

## 原则

不要平均配图。优先选择"认知锚点"：

- 核心判断
- 两个断点
- 输入输出闭环
- 分流
- 前后对比
- 一鱼多吃
- 承接路径
- 常见坑
- 角色状态变化

## 数量建议

| 文章长度 | 封面/首图 | 正文插图 | 总计 |
|----------|------|----------|------|
| 短（<1500字） | 1 | 1-2 | 2-3 |
| 中（1500-2500字） | 1 | 2-4 | 3-5 |
| 长（>2500字） | 1 | 3-5 | 4-6 |

不要超过 6 张。够用就好，避免把正文做成画册。

## Shot List 格式

为每张图写清楚：

```
图 01 — 首图
- 类型: editorial-cover / cinematic-character-poster
- 位置: 文章首图
- 主题: ...
- 核心句: ...
- 场景隐喻: ...
- 如果是 cinematic:
  - 主角: 读者化人物 / 匿名案例主角 / 作者视角 / 群体代表
  - 压力: ...
  - 选择动作: ...
  - 文章承接段落: ...
  - 禁止画: 未证实结果 / 真实品牌 / 平台 UI / 奖项 / 水印

图 02 — 正文插图
- 类型: editorial-inline / cinematic-inline / xiaohei
- 位置: 第 5 段后
- 主题: ...
- 核心意思: ...
- 结构类型: Workflow
- 小黑动作: ...
- 如果是 cinematic-inline:
  - 分镜节点: 开场处境 / 压力逼近 / 旧路失效 / 关键选择 / 行动代价 / 抵达回望
  - 段落功能: ...
  - 主角连续性: ...
  - 核心物件: ...
  - 禁止画: 未证实结果 / 真实品牌 / 平台 UI / 奖项 / 水印
```

## 封面决策树

```
用户明确要金句海报？
├─ 是 → quote-cover（Python 本地渲染）
└─ 否 → 文章是否有强人物故事、选择、转型或案例冲突？
       ├─ 是 → 四问是否全过：主角 / 压力 / 选择动作 / 文章承接？
       │      ├─ 是 → cinematic-character-poster
       │      │      ├─ 21:9 文章首图
       │      │      ├─ 1:1 分享封面（需要时）
       │      │      └─ 4:5 风格探索/海报候选
       │      └─ 否 → editorial-illustration
       └─ 否 → editorial-illustration
              ├─ 21:9 文章首图
              └─ 1:1 分享封面（需要时）
```

## 正文插图原则

默认在 editorial-illustration 和小黑之间二选一，不再做结构化图解或表格。

editorial-illustration 适合：

- 商业隐喻
- 群体状态
- 路径变化
- 内容、产品、用户之间的关系
- 情绪克制的文章段落过渡

cinematic-character-poster 适合：

- 学员/客户/普通人的故事
- AI 时代职业选择
- 转型、压力、孤独行动、失败复盘、成功故事
- 需要强封面点击，但仍要保留公众号质感的文章
- 正文中需要用分镜承接阅读节奏的段落

cinematic-character-poster 可以承担正文阅读分镜。叙事型文章可用 2-4 张 cinematic 正文图；长篇人物故事或明确视觉专题可到 5-6 张。每张必须绑定一个段落功能，例如开场处境、压力逼近、旧路失效、关键选择、行动代价、抵达回望。正文解释、方法拆解、机制说明默认继续用 editorial-illustration 或小黑；如果用 cinematic，必须把方法变成角色动作或场景变化，而不是画流程图。

小黑适合：

- 系统里的脏活
- 荒诞的产品动作
- 一眼看懂的单个机制
- 需要“白纸产品草图”气质的段落

小黑必须承担核心动作。如果去掉小黑，图仍然能讲通，说明它只是装饰，要重写。
