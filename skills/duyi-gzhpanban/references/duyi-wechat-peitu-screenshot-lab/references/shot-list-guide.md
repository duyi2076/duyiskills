# 配图策略指南（Shot List）

## 原则

不要平均配图。优先选择"认知锚点"：

- 核心判断
- 两个断点
- 输入输出闭环
- 分流
- 前后对比
- 一鱼多吃
- 承接路径
- 常见坑
- 角色状态变化

## 数量建议

| 文章长度 | 封面 | 小黑插图 | 总计 |
|----------|------|----------|------|
| 短（<1500字） | 1 | 1-2 | 2-3 |
| 中（1500-2500字） | 1 | 2-4 | 3-5 |
| 长（>2500字） | 1 | 3-5 | 4-6 |

不要超过 6 张。够用就好，避免把正文做成画册。

## Shot List 格式

为每张图写清楚：

```
图 01 — 封面
- 类型: cover
- 位置: 文章首图
- 主题: ...
- 核心句: ...

图 02 — 正文插图
- 类型: illustration
- 位置: 第 5 段后
- 主题: ...
- 核心意思: ...
- 结构类型: Workflow
- 小黑动作: ...
```

## 封面决策树

```
文章有核心判断句？
├─ 是 → quote-cover（Python 本地渲染）
└─ 否 → 小黑正文插图作为首图
```

## 正文插图原则

默认只选小黑插图，不再做结构化图解或表格。

小黑必须承担核心动作。如果去掉小黑，图仍然能讲通，说明它只是装饰，要重写。
