# 图文交付、核查与归档

生成预览、排版或保存时读取。按用户选定形式交付；默认是可离线阅读的大字单栏 HTML。固定纸张、卡片、两张长图或某个风格只在本轮明确选择时采用。

## 默认文件与位置

在指定工作目录或当前项目中选专用目录，遵守现有归置规则。避免覆盖已有文件，保存版本与采纳状态，不将新稿自动替换身份原件。

- `个人说明书与自用资料指南.md`：合篇可编辑正文；仅介绍模式用对应标题。
- `个人说明书与自用资料指南.html`：默认阅读版本。
- `分享资料/` 或真实外部入口：获准分享的实际资料，保留作者归属和版本。复用已有固定入口时不另复制完整资源库。
- `个人介绍_简介版.md/html`：用户要求或快速转发确有需要时提供，与主文事实一致。
- `配图/`：安全展示图片，原件有固定位置时按库规则复用。
- `阅读入口.md`：关联阅读文件、正文、图片、分享资源和已生成的远程文档。
- `内部记录/`：素材依据、核查与未完成项，不混入对外正文。

指定飞书时以合篇飞书文档作为阅读版本，保留本地正文、配图和入口；另要简介时才增加文档，未另要 HTML 时不强制生成全部格式。只要文案时交付正文，不擅自创建远程文档。

HTML 图片可以内嵌，链接到的模板、表格等资源不会自动内嵌。使用相对链接时把所需资源放在交付目录，移动、打包或归档后再次核查；孤立转发一个 HTML 不能称为完整资料包。外部入口记录检查时间、可见范围和未验证的登录或取用条件，不将本机路径冒充公开下载地址。

知识库归档按库规则选择身份或业务说明位置，读取说明文件与已有原件。正文、图片、资源去向和阅读入口留在库内，HTML、脚本与开发产物按工作目录规则存放并关联，不复制底层原始资料。归档已有飞书版本时保留远程链接、可读正文、原有图片和真实资源入口，不用新草稿替换原版。

## HTML 渲染

正文基准字号 20px、单栏最大宽约 720px、行高约 1.8，手机窄屏自适应，保留浏览器缩放。标题、正文和图注有清楚层级，图片支持点按放大，宽表在窄屏可横向查看。值可随用户选择调整，不将固定 A4 尺寸当手机限制。

可使用薄封装脚本：

```bash
python3 scripts/render_article.py --input NOTE.md --output NOTE.html --asset-root IMAGE_DIRECTORY
```

从 Skill 目录运行，或传脚本绝对路径；带空格路径正确引用。`--title` 可指定标题，默认取首个一级标题或文件名。默认拒绝覆盖，只有覆盖已获授权且对象明确时使用 `--overwrite`。

解析器复用 [markdown-it-py](https://github.com/executablebooks/markdown-it-py)，许可为 MIT；脚本只加单栏样式、本地图片内嵌、缩放与图片放大。所需包 `markdown-it-py`，先检查当前 Python 环境，不假定另一个客户端共享环境。缺包可用当前成熟渲染能力生成等价 HTML；需安装时说明位置并沿用任务授权，不改全局环境或自行写完整解析器。

支持标准 Markdown 图片和 Obsidian 图片嵌入。图片从输入父目录或明确的 `--asset-root` 查找；源图超出范围时提供授权素材根目录或将图存入交付目录。缺图、歧义、越界路径、远程图片和不支持格式会报错。远程图片用获准的来源能力保存到本地并核查，不能替换图片让验证通过。

脚本去掉闭合的元数据区块，未闭合时报错；禁用原始 HTML 输入，将图像内嵌且不修改原图。无需外部字体、脚本、样式或额外网络请求；成功报告路径和图片数量。它不判断图像是否适合公开，匿名与证据核查须在渲染前完成。

## 指定飞书文档

用当前飞书工具；安装了 `lark-cli` Skill 时读取对应说明与实际 CLI 帮助，不依赖历史命令结构。没有写权限或工具时完成本地稿，明确远端未完成，不虚构链接或重置鉴权。

创建或更新在授权范围内，仅改要求的部分，保留手工内容和图片。标题、正文、列表与强调用飞书原生格式，不把 `**`、`#` 等源码留成可见正文。

按可读性调整截图宽度和段落间距，不降低原图清晰度。文字复制、图像上传、链接创建各自核验，上传成功不等于已在正文显示。

写后重新读取文档并打开实际页面。比较含义时排除纯排版差异，但保留正文、数字、时态、主体和链接目标；检查图片数量、顺序及对应关系。格式错误先修受影响的块，不为重排整篇删除再写。

## 验收与记录

记录可观测结果及未完成项：

1. 各版与源材料含义一致，关键事实、实际资源、当前提供内容及边界无遗漏。
2. Markdown 图片可解析，HTML 内嵌图片或飞书图片实际存在且顺序正确，原图来源可查。
3. 在手机宽度约 390px 下查看真实成品，检查正文、图注和截图；试用文字缩放、图片放大、关闭大图、窄屏表格及链接。有实际设备条件时按其验收。
4. 原图与最终可查看图均检查隐私；能打开的未遮盖原图不算匿名通过。
5. 打开实际资源或入口，核对内容、许可、版本、首用说明与必要条件。静态文件只需核查可读与内容相符；工具有运行条件时再做获准且适当的首用检查。未执行的功能不称已运行通过。
6. 本人采纳有明确依据；归档文件、资源及入口写后读回；权威原件未被意外替换。

静态检查可确认路径、文件、图片和样式，不能证明视觉可读性或本人采纳。浏览器、远端权限或设备不可用时记清未验证项，交付已有文件，状态保持“交付待完成”。不换路径、浏览器或工具绕过访问拒绝。

本人采纳且所需检查通过时报告完成，否则分别汇报文案、本人采纳、成品核查和保存状态。
