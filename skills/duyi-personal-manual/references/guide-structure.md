# 合篇结构与资源指南

写个人说明书与资料指南合篇时读取。面向刚从公开内容认识本人的读者，先让他得到有用的东西，再提供继续了解本人的依据。复制参考稿的章节作用，不复制作者的身份、资源数量、产品或结果。

## 主文顺序

开头用一小段讲清本人现在做什么、给谁准备了什么礼物，以及继续阅读能了解什么。只留认识所需的信息，经历细节放后面。

| 位置 | 读者想知道什么 | 写入的内容 |
|---|---|---|
| 1. 给新读者的小礼物 | 能帮我什么，在哪拿，怎么开始？ | 适用情境、资源清单、真实入口、准备条件和第一步 |
| 2. 这些资料与经验从何而来 | 为什么这个人值得了解？ | 相关工作、亲身实践、作品、服务记录、调整与配图 |
| 3. 我现在主要帮大家推进什么 | 他现在关注什么，具体怎么做？ | 实际问题、帮助对象、推进动作；有服务才写实际提供内容 |
| 4. 实践或参与者的真实案例 | 有哪些具体行动或作品？ | 起点、动作、目前进展和结果；优先与礼物或帮助方向相关 |
| 5. 什么样的人适合关注我 | 和我的处境有关系吗？ | 可辨认的处境、需求和必要使用条件 |
| 6. 怎么连接我 | 为什么继续看，如何联系，有哪些边界？ | 真实渠道、自愿关注理由、资料更新安排、本人确认的联系与支持边界 |

标题用当前作者与读者的语言。没有商业产品不写课程或报名；没有客户案例可放本人作品或使用过程；没有案例材料则省去该节。合并后也要保留“先取用、后了解、再自愿连接”的阅读关系。

主文交代第一次使用所需的信息，详细教程留在真实资源内。不要把资源目录、使用指南、个人经历重复写成三套长篇介绍。群公告、口播、领取话术只在本轮要求时另做，不默认加入主文。

## 资源盘点与选择

先读资源内容并问清本人怎样使用，再决定是否推荐。内部表记录：

| 字段 | 必须弄清的事 |
|---|---|
| 读者问题与用途 | 在什么情境下使用，帮他完成哪一个动作 |
| 本人使用依据 | 自制还是第三方；本人具体如何用；现成资源还是新整理草稿 |
| 实际内容与产出 | 模板、表格、清单、工具、短指南、方法或案例，以及能直接得到什么 |
| 起步与条件 | 要准备的材料、设备、账户、费用与必要技能；没有就不添限制 |
| 获取方式与权限 | 文件或链接是否存在；允许分享文件还是只能指向原作者公开入口 |
| 状态与边界 | 可用性检查结果、版本、是否提供更新或答疑；未确认的承诺不写 |

优先挑读者眼下能用、本人实际熟悉、允许分享的一小组。数量由材料决定，不凑固定数量。第三方资源写清作者归属；可分享链接不等于可再分发整份文件或代码。

没有现成文件但有真实做法，可先整理最小清单或短指南供本人审阅。新稿不借用“自用多年”“已验证”“已经开源”等信用；未取得授权或未做成资源时，不在主文展示可领取的假入口。

## 用读者的语言写资源条目

推荐形式：**解决的事**，接一两句说明“适合什么情况、怎么用、会得到什么”。工具或专业名称放在必要位置，不能只列名词。

每项资源或同类资源的共用说明，覆盖：

1. **什么时候用**：读者熟悉的具体场景。
2. **准备什么**：真实需要的输入、设备或账户。
3. **从哪一步开始**：一条能照着执行的动作，不停在“自行配置”“直接使用”。
4. **会得到什么**：输出或帮助，区分工具产出和外部结果。
5. **怎样确认与限制**：使用结果的简单判断；已知限制、费用或本人确认的支持边界。

不必逐项重复五个小标题。几项共享起步方法时只写一次；操作不同的资源分别写清。例如读书记录模板先说“读完容易忘，用它留下问题、摘录和自己的理解”，再说明复制模板、填写一页、回看哪些内容，不能从模板推出保证记住整本书。

如果是 AI 工具，必要时简要解释 Skill（技能工作流）等名称，并依据实际说明给安装和首用方法，不承诺所有工具都能一键安装。不是 AI 工具就不用 AI 术语、代码安装或电脑限制。

## 领取与后续关系

入口指向资源文件、仓库、文档、原作者页面或本人确认的领取渠道。写明入口内有什么、如何拿到和第一次怎么做。需要联系本人才能领取时如实写步骤；公开自取的内容不额外设为必须加好友才能拿。

资源、免费内容、咨询、付费服务分别按本人确认的范围说明。不暗示领取包含无限答疑；也不默认替作者宣布不答疑。没有付费服务时保留真实实践与关注理由即可。

连接方式由本人选择，可以是公众号、邮件、微信或其他真实渠道。表达允许围观与自愿继续了解，不制造必须报名、限时名额或尚未确认的更新频率。
