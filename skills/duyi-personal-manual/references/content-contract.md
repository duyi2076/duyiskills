# 内容契约与素材选择

起稿前读取。适用主体是本次被介绍的人；结构承接实际材料与用途，课程、AI、自媒体或任何商业模式都不是所有人的默认章节。合篇另读 [合篇结构与资源指南](guide-structure.md)。

## 最小材料和内部记录

至少知道读者与场景、本人目前在做什么，以及一项能支撑介绍的真实经历、作品或当前行动。已有材料直接读取；没有库时本轮口述可成为来源。不要要求正式证明、精确日期和大成绩才能给草稿。

更新介绍时读取本人指定的现行原件，并与已有稿核对冲突。本人明确采纳的新事实优先于旧稿与测试产物；来源时间较新但确认状态不明时回查，不能只凭文件名、修改时间或“最新版”标签认定权威。将冲突及采用依据留在内部记录。

内部素材依据表使用以下字段，具体记录放工作目录：

| 字段 | 内容 |
|---|---|
| 可用事实或原话 | 保留原来的主体、动作、时间和结论强度 |
| 主体与来源 | 本人、客户或他人；文件、段落、链接或本轮口述位置 |
| 状态与时效 | 本人事实、偏好、建议或未确认；发生时间与采集时间 |
| 公开范围 | 本人允许公开、需要匿名、仅内部或尚未明确 |
| 对应图片 | 文件、原图位置、可见信息及其能证明的具体内容 |
| 缺口 | 冲突、缺失与最少补问；无关键缺口不强行填写 |

来源无需公开写进成稿，但必须能内部回查。数据按实际口径写：合计关注数说明平台范围和是否去重；营收、利润、个人收入分开；购买、报名、发布、交付和用户结果分开。

本人要求展示过去服务或报价，不等于确认现在仍接单、仍使用该价格。材料只说“做过”或描述历史经历时，在经历段写过去的服务，不能改写为“我现在承接”“目前可以购买”。当前服务状态未明确时定向补问或只写已有经历，不用新设服务填满结构。推导也不能冒充亲身经历、转折动机或本人已表达的判断。

## 介绍模式与版本职责

**合篇模式**默认交付一份个人说明书与资料指南，围绕真实礼物、使用方法与本人介绍组织。正文资源清单、附件、领取入口和使用说明必须对应同一版本，不能仅列资源名就算已提供。公开资料可取用、本人长期自用、允许再分享、有人取得结果是不同事实，分别有依据再表述。

**仅个人介绍模式**不要求准备见面礼。本人有经历、作品或当前行动即可成稿。按本轮场景选择一版；需要长短两版时分工如下，不自动生成两份长篇。

**简介版**让第一次认识的人回答五个问题：

1. 这个人现在做什么，和我的问题有什么关系？
2. 有哪些相关经历、作品或行动，让介绍具体可信？
3. 目前可以向他了解什么或获得什么？
4. 如果涉及服务，给谁用、实际提供什么，有什么参与条件？
5. 如何继续了解或联系？

不必为每项安排独立标题。用一条真实主线串联过去与现在，优先删无关标签、重复解释和过多工具名。没有服务时省去第 4 项；联系信息未知且不能代填时，用已有了解入口，或在内部记录留缺口。

**展开版或合篇中的经历部分**在同一主线上展开相关经历与转折、实际作品和案例、当前产品或服务、参与条件与了解入口。无材料的章节省去，不能把别人的课程结构或案例写成自己的内容。所有版本的身份、资源状态、产品、数字、时态和承诺必须一致。

不要机械压缩完整版为简介。先确定初次认识的人必须知道什么，再独立组织简介；详情由完整版承接。长度由场景与材料决定，用户给定限制优先，避免为凑固定纸张、截图张数或字数损失必要内容。

## 用户语言与交付说明

涉及陌生工具或方法时，用“读者碰到的问题 → 具体怎么协助 → 实际提供或需要他做的事”组织，再保留必要名称。例如资料归档流程可解释为“把散落的经历、用户问题和作品存到自己的资料库，后续写介绍时不用重新找材料”。这只是表达结构，具体能力由本人材料决定。

服务或课程需要区分：

- **实际提供的东西**：资料、模板、教程、工具、讲解、答疑等。
- **参与者要做的动作**：提供资料、练习、制作、测试、核对与决定。
- **实战目标与外部结果**：计划完成的作品不能写成保证完成；测试收费不能写成保证收入。
- **安排与边界**：历史与现行期次、服务时长、群内或一对一、必要设备和参与时间，以本轮资料为准。

适合或建议暂缓的人用实际条件表达，如“近期无法留出练习时间”，不用人格评价或抽象标签替代条件。只有实际工具或课程需要电脑时才列为限制，不能套给所有业务。

## 配图的证据关系

每张图至少回答“它支撑相邻哪一句，是否比文字更便于判断”。优先相关作品、实际服务现场、明确记录和用户行动过程，不用无关截图凑图。

- 现场照片支撑发生过讲解或培训，单独不能证明收费或效果。
- 订单和付款按可见范围说明，不能推出全渠道收入、净利润或普遍成交能力。
- 发布产品、开始招募和完成分享是不同进展，不能仅凭它们断言已赚到钱。
- 原图、本人自述和 AI 推断的证据强度不同，图中读不清的文字和金额不猜。

把图放在对应论断附近，图注说明读者需要理解的场景与时间。遮盖无关识别信息，保留与证明有关的真实内容；用可用且获准的编辑能力保存单独匿名版本，逐图复核，不回写原件。不能可靠匿名时换图、暂不使用，或补齐使用范围。

证据关系在内部核查，图注用场景、时间和实际动作帮助读者看图。不要把“本轮核查”“图片能证明什么”“不代表额外承诺”这类执行说明写进正文；避免误解时直接用准确时态、实际进展或必要数据口径表达。

匿名检查含正文图片、缩略图、标题昵称、头像、群名、二维码、账户与订单信息。不能仅用网页遮罩或 CSS 模糊隐藏原图，因为可打开的原图仍会暴露信息。作者允许使用的本人公开账号与联系方式按其选择处理。
