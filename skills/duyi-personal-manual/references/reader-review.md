# 自检与读者试读

图文稿与资源指南形成后读取。找到实际文案和取用过程中的理解缺口，不是收集越多疑问越好。

## 自检

逐版检查身份与当前行动、读者与自己的关系、可信依据、当前提供内容与条件、术语、重复、图文对应，以及历史、现行安排和未来计划。合篇另检查礼物是否有实际内容、为什么对该读者有用、入口与首用动作是否清楚。

没有服务时不要求交付、价格、报名齐全；没有成绩时看真实行动与作品能否支撑介绍。每版分别能独立理解，再核对事实与承诺一致。缺现成资源时分清候选、草稿与可领取内容，不能把新制作的指南审成“已经验证过的自用资料”。

取用核查用实际资源：打开文件或获准访问的入口，确认内容与清单对应、能找到第一步、需要的输入与条件真实、联系方式准确。链接存在不代表成功取得文件，取得文件不代表工具运行通过。仅能检查正文时如实记录资源功能未验证，不用模拟读者意见代替实测。

## 选择读者与执行方式

按场景选择一到两种有实质差异的视角，例如首次认识作者的人、已有相关问题且正在比较服务的人、熟悉业务但不熟悉工具的人。简单介绍可由主代理自检和模拟；复杂介绍、多类读者或关键误读未解决时可独立子代理试读。

代理只读。给目标读者场景、实际版本正文、可见配图，以及作者向读者公开的资源或领取入口；不给素材底稿、历史讨论、期望答案或已知问题。只能审文字时注明没有审图片或资源。无法委派时主代理模拟并保留实际方式，不伪装成独立或真人测试。

可使用以下任务说明：

> 请站在指定目标读者的处境，只看这一版介绍、配图和读者可取得的资料。先扫读，再细读，回答：你认为作者目前做什么；哪些信息使你觉得可信；与你有什么关系；礼物具体帮你做什么；从哪里拿、拿到后第一步做什么、是否还有必需条件；领取是否意味着咨询或付费服务；有没有仍不清楚、误读或读不下去的地方；你是否愿意继续了解，为什么。每个判断注明句子、图片或资源位置。没有礼物时跳过相应问题。不要调用作者其他背景，不要评分或推断成交率。

区分值得继续看与服务适合我。没有服务时只检查关注或联系理由，不强行判断购买。

## 合并与修改

记录位置、读者原理解、问题、证据和修改动作。去重后分类：

| 问题 | 修改方式 |
|---|---|
| 身份、服务、结果或时态被误解 | 改核心句；缺事实时定向补问 |
| 工具名、抽象词挡住理解 | 换成具体问题、动作或提供内容，删无关术语 |
| 有资源名却不知怎么取得或开始 | 补真实入口、第一步和必要条件；缺实际资源则回到盘点 |
| 领取被理解为无限咨询、自动成功或必须购买 | 改实际提供范围、参与动作与自愿连接说明 |
| 详情缺失但不影响初次判断 | 放资源内页、展开版或后续入口 |
| 同一信息重复 | 合并或删去，保留最清楚的一处 |
| 图片不对应、过密或不可读 | 换图、拆分呈现或移除；不凭文字通过图片审查 |
| 读者目前不需要服务 | 保留边界，不为让所有人代入而扩大范围 |

修改后复查受影响部分。同一个核心误读仍存在时，回到事实与目标，指出具体未解决问题，停止机械追加段落和无实质变化的重复审稿。

试读、本人采纳和实际用户反馈分别记录。模拟能发现误读，不证明真实人群比例、关注率、报名率或收入。
