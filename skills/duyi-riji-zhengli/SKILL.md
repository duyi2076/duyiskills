# 杜一日记整理

整理用户提供的真实记录，保留口吻、判断强度、相对时间和不确定性。只从原文提炼，不补经历、成绩、因果、情绪或任务。默认在聊天中交付，不需要配套资料库。

## 输入与分流

1. 使用用户贴出的文字、附件或明确指定的文件。只有用户指定目录与日期时，才在该目录内定位对应日记；找不到时询问必要位置，不自行扫描私人目录。
2. 完整阅读指定范围，确认输入是口述转写、本人笔记、已整理稿还是二次摘要。只有转写时，不声称回听录音；二次摘要不能冒充原始口述。
3. 记录日期来自用户说明或原文。文件名与正文冲突、相对时间不能确认时，在记录边界保留疑点，不默改日期。多天材料逐日区分，不把“昨天”发生的事写成今天已完成。
4. 未整理的原始记录走完整梳理；已有“记录边界”与原文附录的稿件只修改用户指定部分；旧格式补齐原文实际支持的缺项，不整体重排。

材料没有原始口述时，仅整理现有输入并说明来源身份。需要找回原话，只在用户另行要求且授权来源读取时使用可用工具；不默认读取账号、登录数据或其他笔记，不因工具缺失停止现有整理。

## 八段结构

依次交付以下结构。格式控制组织方式，不要求凑够事项或判断数量。

1. **开头总结段**：一段话概括当日主线，包含实际事项、原文已有判断和下一步；不加重复的大标题。
2. **主题分节**：按共同主题组织，使用 `## 主题：要点`，以列表保留动作、细节、条件、感受和结果。可以重组口述顺序，不能改因果或把不同日期拼成同一事件。
3. **今天真正想清楚的几件事**：仅列原文明确表达已形成的认识或判断，通常用引用块。整理过的表述标“原话整理”，只有逐字复制才作为原话引用；想法、讨论和假设不升格为决定。“还没决定”“没想清楚”等表述保留在对应主题内，不能为填此栏目搬入；本次只有这类未定想法时省略本栏。
4. **今日待办完成情况**：沿用原任务顺序，明确完成用 `- [x]`；未完成用 `- [ ]`。原文没说完成情况，注明“记录未提及，待确认”，不替用户勾完成。
5. **接下来围绕这个板块行动**：用 `- [ ]` 仅列原文已有的下一步。设想尚未决定时保留设想身份，不新增期限、数量、优先级或建议任务。
6. **记录边界**：简短说明实际输入范围、来源身份，以及影响理解的日期疑点、指代理顺、转写疑点和事项状态。已在正文明确的内容不重复，不写执行日志或修改成绩。
7. **分隔线**：使用 `---`。
8. **附：今天的原始记录**：先写“以下按原文保留本次提供的原始记录。”，再完整保留输入，包含任务清单、口误、杂音、标点、标题和空行。

原文没有明确判断、任务清单或下一步时，不凑相应章节。记录边界说明本次没有这些内容即可。没有原始记录可用时，不编造附录，明确当前只有整理稿或二次摘要。

## 忠实整理

- 原文中的“可能、打算、还没决定、我感觉、听说”都保留，不能变成事实、已完成事项或经营结果。
- 多人对话、旁人讲话和环境广播不归为日记作者的经历或判断。整理区可省略无关噪声，原文附录保留完整输入；角色不明时标归属待核。
- “昨天、前天”等相对时间优先原样保留。确需推断日期时，在记录边界说明依据，只使用用户指定的辅助材料。
- 编号错乱、明确错字和指代可在整理区理顺；重要人名、金额、专有词不能猜改。附录原话不动。
- 整理部分不使用破折号，原文附录保留原本符号，不为文风改动证据。
- 已整理日记的定向修订只改相关内容；没有授权时，不同时改日期、名字、任务状态或全篇结构。

## 原文保全

原始文件保持不变。把完整输入复制到整理稿末尾的独立代码块中，不调整原文的标题级别、缩进、空行或口误。原文含反引号时，代码块围栏长度须大于原文最长连续反引号，围栏与说明不属于原文本身。

从文件保存原文时，保留原始字节及换行形式；可用文件指纹核对原稿未改，并将附录实际内容与读取到的原文比较。聊天输入只能核对提供的文字，不声称已验证原始音频或文件字节。

需要保存、局部更新或重命名时，读取 [references/file-handling.md](references/file-handling.md)。不得为排版而破坏已有原文附录或重要正文。

## 交付与核对

默认直接交付可复制的完整日记。记录边界属于日记的来源说明；详细来源对照表、处理解释和待用户确认的问题放在单独汇报中，不混入总结正文。

交付前对照输入核对：

- 每条事项、判断和行动是否来自原文，角色、日期和事实状态是否一致？
- 原文没有说明完成的任务是否仍为未确认，建议是否被误写成已决定？
- “想清楚”栏目中的每一项是否确为原文已有认识，未定想法是否留在主题内而非该栏目？
- 整理区是否保留必要条件、细节和口吻，是否新增了原因或情绪？
- 原稿是否完整保留，是否漏掉任务清单、空行、口误或背景讲话？
- 局部修订是否保留其他手工内容，保存后是否实际读回？

说明实际整理的日期与范围、仍待确认项，以及是否保存。未读完或未交付完时分别说明，不把部分整理称为全量完成。不直接发布或同步外部服务。
