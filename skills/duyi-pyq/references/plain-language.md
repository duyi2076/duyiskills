# 清晰表达：ISO 与 ASD 的中文适配

直接执行本附件中的本地规则，不联网、不查阅标准网站。以下是中文适配方法，不是完整标准原文。


采用 ISO 24495-1:2023 的通俗语言原则，并借鉴 ASD-STE100 的清晰表达方法。此处是中文朋友圈的适配规则，不是完整标准条文或合规认证；不把英文词典和英文词数限制套到中文。

- 与读者相关：围绕读者能理解的具体场景，只保留支持主线的信息，不为完整而补无关背景。
- 容易找到：尽早让人知道在讲什么，按事件或因果顺序推进；每段一个重点，步骤确有顺序时用编号。朋友圈默认不加章节标题。
- 容易理解：用常用词和具体动词，交代谁做了什么。拆开同时承载多个意思的长句，避免含糊指代；同一事物保持同一称呼。必要术语首次用日常语言解释。
- 能够使用：方法写清操作与条件；招募写清交付与入口；观点写清判断及适用范围。故事或感受无需强加行动指令。
- 保留声音：保留“爽多了”等用户自然表达，不因简化删掉关键条件、情绪或不确定性，不凭空新增主语和因果关系。

输出前检查：读者能否找到重点、说清发生了什么、理解判断的依据；如果正文给出方法，能否知道如何做。模型自检只表示完成编辑检查，不能冒充真实读者测试或宣称符合全部标准。
