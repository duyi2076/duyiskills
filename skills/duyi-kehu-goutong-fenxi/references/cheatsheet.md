# 戈夫曼拟剧分析速查表

## 快速决策

| 看到的现象 | 优先检查 | 不要直接下的结论 |
|---|---|---|
| 说法与动作不一致 | 给予与流露、独立证据 | 动作一定暴露真心 |
| 不同场合像不同的人 | 观众、情境定义、角色期待 | 没有真实自我 |
| 团队对外高度一致 | 剧班、后台、导演、秘密 | 内部没有分歧 |
| 公开专业、私下混乱 | 前台与后台、能力后果 | 有后台就是虚假 |
| 私聊截图导致翻车 | 区域泄漏、新观众定义 | 原话脱离情境仍同义 |
| 水军或捧场嫌疑 | 托儿、关系披露 | 所有正面评价都无效 |
| 权威保持距离 | 神秘化、合理核验 | 距离一定代表能力 |
| 当场尴尬无人揭穿 | 观众圆滑、运作一致 | 大家真的认同 |

## 八问分析法

1. 这是什么场合。
2. 谁在表演，谁在观看。
3. 各方想维持什么身份。
4. 说出的与流露的是否一致。
5. 什么构成前台。
6. 什么被留在后台。
7. 谁的身份、忠诚、信息和区域权限错位。
8. 哪里会崩溃，谁会救场。

## 修复选择

- **形象不清**：补充前台证据，统一外表、举止和承诺。
- **形象与能力冲突**：优先修复能力，不继续放大前台。
- **团队互相拆台**：重建后台复盘、导演权和升级路径。
- **信息跨区泄漏**：调整权限、观众隔离和转场机制。
- **轻微失误**：承认并接受观众台阶，快速恢复情境。
- **严重伤害**：停止表演性修补，公开责任与补偿方案。

## 理论红线

- 表演不等于虚伪。
- 后台不等于真实自我。
- 流露不等于事实。
- 运作一致不等于价值共识。
- 剧班不等于正式组织。
- 印象管理不能代替真实能力。
- 微观互动不能单独解释宏观权力。
