# 核心术语表

**表演**：特定参与者在特定场合影响其他参与者的全部活动。（导言）

**表演崩溃**：原有情境定义失去可信度，参与者暂时无法按既定角色继续互动。（ch06）

**个人前台**：随表演者移动的表达装备，主要包括外表和举止。（ch01）

**给予的表达**：公认用于明确传递信息的语言和符号。（ch00）

**观众**：接收、核验并回应表演的人，也可能协助维持表演。（ch00、ch06）

**后台区域**：允许准备、修补和出现前台不一致信息的区域。（ch03）

**角色**：可在不同场合重复呈现的预先确定行动模式。（ch00）

**角色外沟通**：正式表演之外承担泄压、协调、复盘和关系试探的沟通。（ch05）

**剧班**：为维持同一情境定义而相互协作的一组人。（ch02）

**流露的表达**：被观察者当作状态、动机或品格征兆的广泛行为线索。（ch00）

**理想化**：突出符合社会价值的特征，隐藏与理想形象不一致的事实。（ch01）

**内部秘密**：以知情资格区分成员和外人的信息。（ch04）

**前台**：稳定定义情境的表达装备，包括舞台设置、外表和举止。（ch01）

**前台区域**：观众可感知、正式情境定义需要被维持的区域。（ch03）

**情境定义**：对场合性质、参与者身份和合理行动方式的共同说明。（ch00）

**神秘化**：通过社会距离和信息限制减少核验，维持权威或敬畏。（ch01）

**受托秘密**：因职业或关系义务替他人保守的信息。（ch04）

**外部区域**：不属于当前表演前台或后台的人与空间。（ch03）

**舞台设置**：支持表演的地点、家具、界面、文件、流程和道具。（ch01）

**戏剧纪律**：控制表达、记住方针并能迅速处理失误的能力。（ch06）

**戏剧谨慎**：预判观众、场地、成员和意外，并准备备用方案。（ch06）

**戏剧忠诚**：保守秘密、服从共同方针并避免前台拆班。（ch06）

**运作一致**：参与者为继续互动而形成的临时公共安排，不等于内心认同。（ch00）

**战略秘密**：涉及意图、能力和计划，泄露后会让对方提前反制的信息。（ch04）

**自我**：由场景、表演、剧班和观众共同生产并归属于个人的戏剧效果。（ch07）
