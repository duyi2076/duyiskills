# 第四章：不协调角色

## 核心思想

通常情况下，表演者、观众和局外人分别拥有不同的信息与区域权限。不协调角色打破这种对应关系，使公开身份、实际忠诚、掌握信息和进入区域发生错位。

## 秘密类型

- **隐秘秘密**：与公开形象冲突，泄露会直接损害可信度。
- **战略秘密**：与意图、能力和计划有关，泄露会让对方提前反制。
- **内部秘密**：用于区分成员与外人的知情资格。
- **受托秘密**：因职业或关系义务替他人保守的信息。
- **自理秘密**：知道别人的秘密，但没有由自身角色产生的保密义务。

同一信息对不同角色可能属于不同秘密类型。

## 主要不协调角色

| 角色 | 公开位置 | 实际功能 |
|---|---|---|
| 告密者 | 剧班成员 | 向观众或对手泄露后台信息 |
| 托儿 | 普通观众 | 与表演者串通，引导其他观众反应 |
| 秘密监督人 | 普通观众 | 代表机构或规则进行隐蔽检查 |
| 探子 | 合法观众 | 为竞争者或其他利益方收集信息 |
| 中间人 | 双方协调者 | 同时掌握双方秘密并调节信息 |
| 无足轻重者 | 身体在场但被忽略 | 因被当作不在场而接触大量信息 |

## 四维判定法

分析一个可疑角色时，不先判断善恶，先填四项：

1. 他看起来是谁。
2. 他实际服务谁。
3. 他知道什么。
4. 他能进入哪里。

错位越大，越可能影响表演稳定。

## 实例重构

直播间里，某账号表现为普通消费者，却持续提出预设问题并带动购买。如果其实际由商家安排，它就是托儿。问题的核心不只是赞美是否真实，而是观众被隐瞒了反应者与表演剧班之间的关系。

## 反模式

- 把中间人、监督人或托儿一概道德化。
- 只看信息内容，不看获取信息的角色与区域。
- 忽略被当作“不在场”的工作人员、儿童或技术人员。
- 认为有合法进入权限，就一定有合法使用信息的权限。

## 实用问题

1. 这个人的身份和忠诚是否一致。
2. 他获得信息的方式是否符合观众预期。
3. 他是否利用区域权限完成另一方的任务。
4. 关系一旦公开，会不会改变其他人的判断。
5. 应调整的是披露、权限、边界还是角色本身。
