# 导言：互动、表达与情境定义

## 核心思想

面对面互动发生时，人们无法直接知道彼此的能力、动机和真实态度，只能根据可见信息进行推断。个体会通过表达影响他人的推断，观众也会核验、修正或拒绝这种呈现。

## 核心框架

### 给予的表达与流露的表达

- **给予的表达**：公认用于传递信息的语言、声明和正式符号。
- **流露的表达**：被观察者当作状态、动机或品格征兆的动作、语气、节奏和表情。

使用时分四步：

1. 分开记录说了什么与表现了什么。
2. 判断观众更信任哪类线索。
3. 检查看似无意的线索是否也被管理。
4. 观察不一致如何影响他人的行动。

### 情境定义

情境定义是一套对互动现实的暂时说明：

- 这里是什么场合。
- 参与者彼此是谁。
- 什么行为合理。
- 谁可以要求什么。

情境定义具有道德性质。呈现某种身份，也意味着承诺言行与该身份相配。

### 运作一致

运作一致不是内心认同，而是为了避免公开冲突和互动停滞而建立的临时妥协。

判断一场互动是否依赖运作一致：

- 参与者是否回避某些分歧。
- 是否默认谁有权定义哪些事务。
- 是否彼此保留面子和解释空间。
- 一旦共识破裂，互动是否会失去方向。

## 心智模型

- 把互动看作一场共同进行的情境定义，而不是单方面的信息发送。
- 第一印象之所以重要，是因为开局立场会限制后续可以自然切换的身份。
- 观众不是被动接收者，他们在观察、核验和协助维持现实。

## 实例重构

一个顾问首次见客户时，用案例和术语给予“专业”的表达。客户同时观察他对细节的反应速度、是否回避风险、团队成员是否配合。如果正式说法和行为流露不一致，客户可能重新定义情境，从“专家咨询”改为“销售推销”。

## 反模式

- 把非语言信号直接当作内心真相。
- 只研究说话者，不研究观众如何回应。
- 把暂时没有冲突误认成真正共识。
- 忽略身份呈现带来的权利与义务。

## 关键问题

1. 当前各方分别如何定义这场互动。
2. 哪些线索被用来核验正式说法。
3. 谁拥有开局定义权。
4. 表面共识依靠哪些沉默和边界维持。
5. 一旦定义崩溃，谁最容易陷入尴尬。
