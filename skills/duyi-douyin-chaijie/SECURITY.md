# 运行与数据边界

本 Skill 在使用者的本地环境运行。只使用可信的输入材料、工具与依赖。

## 公开页面

公开页面入口只接收无用户名、密码的 HTTP / HTTPS 抖音地址。媒体下载使用公开页面提供的媒体地址，不能把流程用于后台内容、付费内容或绕过权限。

## 本机数据

采集元数据不保存当前登录用户名，下载记录不保存 Cookie Profile 绝对路径。不导出或提交 Cookie 文件。

原始证据、运行日志可能包含本地路径和临时媒体链接，应保存在包外。分享最终报告前检查评论、图片、原文和链接的分享范围。

密钥、环境文件、浏览器 Profile、私有 ASR 代码和凭证不进入 Skill 源码、公开包或报告。私有适配器只通过显式包外路径调用。

## 依赖

只从系统已有的可信包管理器与官方包源安装依赖，来源见 [运行依赖](references/runtime-dependencies.md) 和 [第三方说明](THIRD_PARTY_NOTICES.md)。不猜测包名或下载未知安装器。
