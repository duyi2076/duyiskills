# 结构拆解分类表

## Hook Types

Hook can have multiple labels. Do not force a single type when the opening combines result, list, conflict, and identity pressure.

- 反常识：第一句否定目标用户的常见认知。
- 痛点直戳：第一句直接点出具体场景里的难受结果。
- 结果前置：先给结果、收益、损失或结论，再解释路径。
- 身份召唤：点名一类人，让目标用户确认“在说我”。
- 冲突悬念：把对立、风险、误解或未完成信息放到开头。
- 案例开场：用一个具体人、具体事、具体金额或具体变化开场。
- 清单承诺：用“三条/五个标准/几个问题”让用户预期后面有结构。
- 冒犯式归因：把用户的失败归因到心理、认知、逃避、懒惰等刺痛点。

## Expression Styles

- 粗暴二分：你做 A 就有结果，不做 A 就没有结果。
- 先冒犯后解释：先给刺痛判断，再说“先别急着喷我”并解释标准。
- 闭卷考试：用具体问题逼用户验证自己是否真的懂。
- 口语压迫：短句、重复、反问、直接点名借口。
- 咨询化表达：抽象术语较多。迁移时慎用，容易丢失原视频语气张力。

## Retention Mechanics

- 信息阶梯：每 3-5 秒给一个新事实、新判断或新例子。
- 延迟兑现：先提出问题，隔一段再揭示答案。
- 反复转折：用“但真正的问题是”“很多人忽略了”推进。
- 证明补强：用评论、截图、数字、经历或对比降低怀疑。
- 节奏切换：画面、字幕、声音、镜头或语速发生明显变化。

## Migration Questions

- 这个结构服务的是哪类人？
- 它解决的是选题、信任、痛点放大、方法交付，还是转化动作？
- 使用者能复用的是结构，还是人设、案例、表达方式？
- 哪些部分不能照搬，因为缺少同等证据或身份基础？
- 有没有跨选题迁移示范，而不只是原赛道换皮？
- 迁移示范是否保留了原作者表达语境？
