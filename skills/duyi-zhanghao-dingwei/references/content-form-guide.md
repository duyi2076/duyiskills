# 内容形式库

不要把赛道名词直接换成另一种赛道的形式。先看读者要解决什么，再看用户凭什么能持续产出。

## 九种形式与门槛

按起步难度排序。前三种不需要第一手经验，新手可以直接做。

| 形式 | 做什么 | 需要什么 | 起步 |
| --- | --- | --- | --- |
| 解释 | 讲清一个概念、现象、变化或误区 | 会查资料，会打比方 | 最适合 |
| 问答 | 回答这个领域的高频问题 | 知道大家常问什么 | 适合 |
| 整理 | 清单、合集、对比表、资源入口 | 会筛选和判断 | 适合 |
| 观点 | 对有争议的事表态并说明理由 | 有立场和论据 | 一般 |
| 案例 | 拆解真实发生的事 | 有素材来源 | 一般 |
| 诊断 | 指出问题在哪、为什么发生 | 有判断经验 | 一般 |
| 方法 | 给步骤、框架、清单、练习 | 自己完整跑通过 | 需要经验 |
| 示范 | 现场做一次，展示前后差异 | 有稳定实操能力 | 需要经验 |
| 过程 | 记录自己的挑战、实验、进度 | 正在持续做某件事 | 特殊 |

"过程"的门槛不在能力而在持续性：它要求用户真的在做事并且愿意公开，做不了假的。

## 形式之间怎么区分

这几对最容易混，选的时候看分界线：

| 容易混 | 分界线 | 例子 |
| --- | --- | --- |
| 解释 / 诊断 | 解释讲"这是怎么回事"，诊断讲"你这里出了什么问题" | 解释：什么叫可交付的产品。诊断：你的 99 元产品一直上不了架，是交付范围没定死 |
| 方法 / 示范 | 方法给步骤，示范现场做一遍 | 方法：从经验到产品走这五步。示范：拿你的一段经验，我现在拆一遍 |
| 整理 / 方法 | 整理给现成的东西，方法给一套做法 | 整理：十个能直接照做的验证动作。方法：怎么按你的情况挑验证动作 |
| 观点 / 解释 | 观点有立场和取舍，解释只求讲清楚 | 解释：两种定价方式各是什么。观点：新手先用低价验证，别一上来做品牌 |

同一个主题可以同时用好几种形式，但不要让它们互相冒充。

## 怎么选

挑 3 到 5 种，同时满足：

- 读者确实有对应的问题，不是只看起来好传播
- 用户有第一手经验、可靠材料或可查证的来源
- 能持续产出，不依赖编造的案例和没发生的结果
- 和主要平台的表达方式兼容

赛道改写成自然说法，但不要丢掉形式的实质。换名字不换实质等于没选。

## 各赛道参考

只说明结构，不要照抄：

- 设计：设计判断解释、改稿过程示范、作品诊断、接单案例、同行问答
- 陪拍：接单流程解释、拍摄现场示范、踩坑诊断、客户案例
- 新媒体运营：平台机制解释、排期与选题示范、数据诊断、账号案例
- 工厂获客：行业认知解释、获客流程示范、询盘转化诊断、成交案例

如果输出只是把赛道名词换了个写法，说明没有真正完成选择，回到读者任务和用户凭据重来。

## 起步内容

前 5 条用于验证定位，不要求把支柱平均铺满。

常见组合：问题解释、常见错误、一次方法或示范、一个真实案例、集中问答。

只有对应材料真实存在时才用，否则按当前赛道和手上素材调整。没真用过的别当测评，没跑通的别当教程，没发生的别当案例。
