# 主页包装生成指南

## 核心目标

简介是陌生人在主页看到的"关注理由"，不是内部定位文档的缩写。

让人快速感受到：为什么值得听这个人讲、关注后会持续看到什么、内容用什么方式呈现、有哪一点值得记住。

不要求逐字回答这四个问题，也不使用固定顺序。

## 先识别简介锚点

从已确认信息里挑最强的 1 到 2 个：

1. 可信身份：真实职业、教育、公司、行业或项目经历
2. 事实证明：作品、结果、年限、更新数量或他人反馈
3. 当前行动：正在做的项目、挑战、实验或连续更新计划
4. 内容承诺：明确的价值、讲解方式、频率或栏目机制
5. 人格记忆点：自然、有辨识度、用户愿意长期用的表达

优先用有事实依据的身份、结果和行动。用户没有强履历时，用"正在持续做什么"建立可信度，不要创造专家身份。

## 选择信息结构

从四类信息里挑最有价值的三类组合：

- 可信身份或真实状态
- 清楚的内容承诺
- 具体的表达方式、栏目或内容范围
- 事实证明、当前行动或人格记忆点

生成 2 到 4 行简介，每行只承担一个作用。按用户事实调整顺序，不强制先写身份。

2 到 4 行仅用于允许多行的草稿。用户或目标字段要求单段时输出单段，不能为了固定结构强行换行。用户已选定的昵称或简介保留原文；为适配容量需改写时展示修改供采用，不静默压缩。

"新手也能跟上""每天两分钟""讲成大白话"这类表达，能让读者自己感受到价值，不必单独写"我能帮某类人"。

## 三种方案

**主题价值型**：内容承诺 + 表达方式 + 内容范围或行动证明。一眼看懂账号持续提供什么。

**个人视角型**：可信身份或经历 + 独特视角 + 内容承诺。身份只能来自已确认事实。

**成长记录型**：当前行动或进度 + 陪伴式承诺 + 表达方式。用持续实践代替虚构的权威。

三套必须结构不同，不能只换昵称或同义词。

## 平台字段

以下是字段类型示例。具体以用户所选平台的当前界面为准；无法核对的字段标“待核对”，不凭记忆编造字数限制。

| 平台 | 主页字段 |
| --- | --- |
| 小红书 | 头像、昵称、2 到 4 行简介、背景图、置顶笔记方向 |
| 抖音 / 视频号 | 头像、昵称、短简介、主页背景、置顶视频方向 |
| 公众号 | 账号名、功能介绍、关注自动回复、菜单结构 |
| 知乎 | 头像、昵称、一句话签名、主页背景 |
| B 站 | 头像、昵称、签名、空间头图 |
| 其他平台 | 先核对真实字段再生成，不要凭记忆编造字数限制 |

多平台共用同一核心定位，只按字段和场景改写，不制造互相矛盾的身份。

用户说不清昵称时，给三个候选让他挑，不要反复追问偏好。

## 字段容量与实际计数

昵称、简介、功能介绍分别处理，不能互相套用上限。上限以用户提供的编辑器信息或已核实的当前字段为准，未知时写“上限未提供”，仍可交付带状态的草稿。没有核验的功能写“待核对”，不因为字段表中列过就宣称当前账号可用。

用随包 [字符计数脚本](../scripts/count_chars.py) 对实际候选逐个计数。例如在 Skill 根目录执行：

```bash
python3 scripts/count_chars.py --text '路线观察笔记'
```

多行简介可用 `--file` 读取只含候选原文的 UTF-8 文件，或用 `--stdin`；不要把标题、Markdown 标记和说明一起算入文案。脚本只使用 Python 3 标准库，读取明确指定的文本，不联网。

默认输出 Unicode 字符数，并另列 UTF-16 单元数与换行数。平台口径与本地计数可能不同；仅在明确平台采用相应口径时指定 `--unit utf16`。已知上限时添加 `--limit`，超限会返回失败状态，修改后重新计数。没有实际统计时不要写实测字数。

在方案说明中列出字段、实际计数、统计单位、上限和余量；未知的上限或余量保持未知。统计说明不放进可复制昵称或简介。通过本地容量检查后，平台是否接受仍以实际编辑器结果为准。

## 避免的表达

除非用户明确喜欢，否则避免：

- 把"我是谁、能帮谁、我的内容"显示成填表标签
- 把"读者认知状态、账号核心价值"等内部术语写进简介
- 缺少事实支撑的抽象头衔
- 罗列过多宽泛领域
- 只写"关注我、一起成长"这类没有具体理由的号召
- 为活泼堆叠大量表情符号
- 添加用户未确认的公司、学历、年限、粉丝数、成绩或作品

## 验收

1. 三秒内能否大致看懂这人是谁或正在做什么
2. 能否知道未来会持续看到什么内容
3. 能否感受到内容的表达方式
4. 是否至少有一个真实、具体、能被记住的细节
5. 所有身份、结果和数字是否经过用户确认
6. 是否自然得像本人介绍，而不是 AI 填定位表
7. 是否符合平台真实存在的字段
