# 两份结果的输出与保存

默认在聊天里完整交付定位总览和账号包装。附带模板是字段参考，不要求用户先创建文件：

- [定位总览](../templates/定位总览.md)
- [账号包装](../templates/账号包装.md)

已使用其他格式的用户，可以沿用其明确选择的字段结构。继续已有定位时，不为套模板重写或迁移原文件。

## 字段覆盖

| 信息 | 定位总览 | 账号包装 |
|---|---|---|
| 个人真实基础与候选赛道 | 真实基础、候选赛道 | 昵称与简介只采用已确认事实 |
| 目标读者、账号价值、一句话定位 | 对应同名字段 | 与昵称简介、内容主线保持一致 |
| 当前业务目标 | 业务与经营约束 → 当前业务目标 | 方案与目标不冲突 |
| 主平台 | 业务与经营约束 → 主平台 | 基础选择 → 主平台 |
| 公开边界 | 可以公开的内容、不能公开的内容 | 可以公开、需要模糊处理、不公开 |
| 每周可投入时间 | 业务与经营约束 → 每周可投入时间 | 用于检查内容主线与首批方向是否可执行 |
| 内容主题、支柱、形式、前 5 条起步方向 | 内容范围 | 内容主线与主页首批方向 |
| 包装候选及推荐理由 | 不重复记录 | 昵称、头像、简介、平台字段、方案选择 |

公开边界有三层时，定位总览的“可以公开的内容”区分直接公开与仅匿名后公开；“不能公开”只记录不可公开的内容。账号包装保留对应三层，不省略匿名要求。

例如用户允许匿名描述同行者时，它属于“仅匿名后公开”，不能写到“不能公开”里。两个文档对同一项目的含义须一致。

业务目标、主平台、公开边界和投入时间被用户跳过时，在对应字段写“待确认（用户跳过）”。如果采用默认平台，写成“暂按小红书；默认值（用户跳过），待确认”，不要写成已选定平台。

## 来源和待确认状态

- 用户事实和已采用偏好进入正式字段。
- AI 建议保留候选或待验证状态，用户选择后可记录为偏好，不因此创造成绩。
- 默认值只能来自已经问过但被跳过的项，保留来源与待确认标记。
- 没有真实经历、结果或材料时，相应字段写待确认或用户明确说明的“暂无”，不通过文案包装补造。
- 未被选择的候选可以保留，标记其状态；不把三套方案都写成最终方案。
- 两到三套方案按用户实际选择展示，不为模板的三行捏造额外候选。最终文件可只保留名称和简介候选，以及已选方案的头像、字段和内容主线；阶段访谈仍需展示完整方案。
- “账号当前阶段”与“第一印象”来自用户明确说明或选择；已有定位文件不证明账号已经创建。未知时标待确认，拟议第一印象注明是 AI 建议，不额外增加必问项。
- 一句话定位采用用户已采纳的自然表达，模板句式只作为要素提示，不二次改写身份、角色或承诺。
- 没有最终确认时，“本人确认”框保持未勾选。用户确认完整内容后，只有明确授权勾选时才代勾选。

来源标签和状态用于定位文档内部记录。可复制到平台的昵称与简介只使用自然表达，不放来源说明、访谈步骤或待确认身份。

## 保存规则

### 未要求保存

只在聊天里交付两份结果，不创建目录或写入文件。最终确认可以在聊天里完成。

### 用户要求保存

使用用户指定的文件路径。只指定目录时，可用 `定位总览.md` 和 `账号包装.md`；没有指定位置时先询问，聊天交付仍可完成。不为了保存而要求安装资料库。

写入之前先完整展示两份结果，并等待用户明确确认。确认定位内容与授权保存分别记录；用户确认方向并不自动授权写入。

### 从零定位

- 目标不存在：用户确认内容及保存范围后，新建指定文件。
- 目标是用户明确指定的空白模板：确认后按字段填写。模板说明、占位符、空表格和未勾选框不算真实内容。
- 目标已有实际答案、已勾选确认框或手工内容：保留聊天结果，请用户指定新目标，或明确改用继续已有定位。不覆盖、不清空，不自行选择其他文件或创建新版本。

### 继续已有定位

- 只读取用户指定的材料和目标文件。
- 先展示本轮要修改的字段及结果，获得确认后再局部写入。
- 保留无关字段、手工段落、表格行、链接、注释和措辞。
- 原结构不含需要的字段时，展示拟新增位置并纳入本轮确认，不擅自迁移结构。
- 多账号分别处理，不把一个账号的用户、平台或业务目标套给另一个。

### 写后核对

1. 重新读取实际保存的两份文件。
2. 检查四项必问已落入对应字段，主平台与公开边界在两份文件中一致。
3. 检查建议、默认值和未确认项仍保留状态。
4. 检查原有手工内容与本轮无关字段完整。
5. 报告保存路径、访谈状态、最终确认状态及仍待确认的项目。没有写入或核对成功时不报告“文件已保存”。

## 完成状态

- **访谈已完成**：四阶段草案已交付，13 个核心项均有回答、前文明确答案或用户跳过记录。
- **定位已最终确认**：用户看过两份完整结果并明确确认，且明确接受其中仍保留的待确认状态。
- **文件已保存**：用户要求保存，范围和内容得到确认，实际写入并读回核对成功。

未保存文件不影响访谈或最终确认；写入成功不能替代用户确认。
