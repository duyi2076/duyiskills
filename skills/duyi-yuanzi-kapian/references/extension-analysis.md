# 延伸分析

仅在用户明确要求加入延伸分析时读取并使用。授权的延伸内容不改变原始卡片的忠实整理要求，也不默认开启所有分析角度。

## 输出位置与归属

先完成原始卡片，再在卡片之后另列【编辑分析】或【编辑建议】，注明对应卡片编号及所针对的具体判断。不得冒用原回答者的第一人称表达新增观点；新增内容应使用编辑视角，不把延伸内容回填“实际回答者的回答与判断过程”。

只保留用户要求且确实增加理解、判断或行动价值的内容。不设置固定理论、商业、反例、跨学科或执行栏目，不换术语重复原建议。

## 每项需要交代的信息

根据内容自然组织，避免机械填表，但需能分辨：

- 针对哪张卡、哪条判断，新增了什么。
- 依据来自哪里，哪些只是编辑假设。
- 是否改变理解、判断或行动，改变在哪里。
- 在什么条件下适用，什么条件下不能照搬。

引用外部理论时查可核验来源并给出链接或可靠出处，不编造名称、来源或引文。无法核实时说明限制。假设反例标为假设，不能写成真实案例。

只有材料实际展开了底层约束及其推导过程时，才使用“第一性原理”名称。不能只用商业口号或另一个学科的术语制造解释深度。

编辑建议与原有下一步分别归属；新增期限、数字、服务要求或完成标准不得冒充原文要求，不能被读成已经承诺或执行。用户对分析的授权不等于授权发布、上传、消费或修改既有承诺。
